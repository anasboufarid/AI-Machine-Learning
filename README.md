# 🤖 AI — Machine Learning Projects

This repository contains my practical implementations and experiments in **Artificial Intelligence and Machine Learning** using Python.

The main goal of this repository is to understand AI concepts by implementing algorithms and models from scratch rather than relying only on pre-built libraries.

## 📂 Projects

### 1. 🧠 Neural Network From Scratch

A simple artificial neuron implemented using **Python and NumPy**.

**Concepts covered:**

* Sigmoid activation function
* Weights and bias
* Forward propagation
* Loss calculation
* Gradient-based learning
* Model training

📄 File: `neural_network.py`

---

### 2. 🔵 Perceptron From Scratch

A simple binary classification model implemented from scratch.

The project uses generated datasets to train the model and visualize the learned decision boundary.

**Concepts covered:**

* Perceptron
* Sigmoid activation
* Training and prediction
* Loss calculation
* Accuracy evaluation
* Decision boundary visualization

📄 File: `perceptron.py`

---

### 3. 📈 Multiple Linear Regression — Insurance Premium Prediction

A Multiple Linear Regression model developed using **Python, NumPy, Matplotlib, and Scikit-learn** to predict insurance premiums based on an individual's income and age.

The project uses a synthetic dataset containing 50 observations and visualizes the relationship between the input variables and insurance premiums using a 3D regression plane.

**Concepts covered:**

* Multiple Linear Regression
* Synthetic Data Generation
* Independent and Dependent Variables
* Model Training using Scikit-learn
* Regression Coefficients and Intercept
* Predictions
* Gaussian Noise
* 3D Data Visualization
* Regression Plane Visualization

📄 File: `linear_regression_insurance.py`
